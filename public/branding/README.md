# Conecta Core — kit vetorial v2

Este kit contém uma **reconstrução vetorial interpretativa** do símbolo selecionado na proposta 01. Não é uma vetorização pixel-a-pixel do estudo de IA. Valide o desenho visualmente antes da adoção definitiva.

## Arquivos
- `conecta-core-simbolo.svg`: símbolo transparente para interface.
- `conecta-core-simbolo-fundo-escuro.svg`: símbolo sobre placa escura.
- `favicon.svg`: ícone em placa clara.
- `conecta-core-logo-claro.svg`: composição para fundo claro.
- `conecta-core-logo-escuro.svg`: composição para fundo escuro.
- `.png`: imagens de verificação rápida, não arquivos de produção preferidos.

## Paleta
Azul-petróleo `#153E47`, teal `#168B83`, grafite `#202C32`, gelo `#F4F7F7`.

## Observação de tipografia
As versões completas em SVG utilizam texto editável e `font-family="Manrope, Inter, Arial, sans-serif"`. O resultado pode variar se Manrope não estiver instalada/carregada. Em produção, recomenda-se carregar Manrope no aplicativo e preferir símbolo SVG + texto HTML/CSS para o nome; ou converter o lettering validado em curvas antes de distribuição como arquivo autossuficiente.

## Escopo
Sem modificações ao repositório, banco de dados, Gmail, Cloudflare, autenticação ou rotas.
